# Student Management System

## Description
This is a simple Java-based Student Management System.

## Features
- Enter student name
- Enter roll number
- Enter marks
- Display student details
- Check pass or fail

## Technology Used
- Java

## How to Run

1. Install Java JDK.
2. Open Command Prompt in the project folder.
3. Compile the program:

javac StudentManagement.java

4. Run the program:

java StudentManagement
